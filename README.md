# SoleStep — Premium Footwear E-Commerce

A complete multi-page e-commerce website for premium footwear, built with HTML5, CSS3, and vanilla JavaScript.

## 🚀 Live Demo

[View the website](https://your-github-username.github.io/shoe-website)

## 📁 Project Structure

```
shoe-website/
├── index.html              # Home page (hero, categories, products, newsletter)
├── search.html             # Search results page
├── cart.html               # Shopping cart
├── product-detail.html     # Individual product page
├── checkout.html           # Multi-step checkout
├── order-confirmation.html # Order success page
├── wishlist.html           # Saved favorites
├── account.html            # Login / Signup
├── css/
│   └── style.css           # All styles
└── js/
    ├── script.js           # Home page logic
    ├── detail.js           # Product detail logic
    ├── cart.js             # Cart logic
    ├── checkout.js         # Checkout logic
    ├── search.js           # Search logic
    ├── wishlist.js         # Wishlist logic
    └── account.js          # Account logic
```

## ✨ Features

- **Responsive Design** — Mobile, tablet, and desktop friendly
- **Product Catalog** — Browse shoes by category (Running, Hiking, Boots, Kids, etc.)
- **Product Details** — Image gallery, size/color selection, quantity, ratings
- **Shopping Cart** — Add/remove items, update quantities, automatic totals
- **Wishlist** — Save favorite items (persists across pages)
- **Search** — Real-time product filtering
- **Checkout** — Multi-step form with validation (customer info, delivery, payment)
- **Account** — Login and signup with form validation
- **Glassmorphism UI** — Modern frosted-glass design effects
- **Session Persistence** — Cart and wishlist saved via sessionStorage

## 🛠️ Technologies

- HTML5
- CSS3 (CSS Grid, Flexbox, Glassmorphism, Responsive breakpoints)
- Vanilla JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Montserrat, Open Sans)

## 📦 Installation

### Option 1: Open directly
Simply open `index.html` in your web browser.

### Option 2: Local server (recommended)
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000`
